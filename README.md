# CICL0 v1.6.0

App HTML standalone di 8s2design per ciclo mestruale e benessere femminile.

- Diario storico, 119 sintomi con intensità, flusso e test.
- Previsioni indicative standard/avanzate, fase luteale personalizzabile.
- Grafici, report stampabile/PDF e backup JSON.
- Farmaci, promemoria nell’app e notifiche browser quando supportate, export calendario ICS.
- Modalità gravidanza e perimenopausa/menopausa.

I dati personali restano nel browser e non sono salvati in questo repository. I backup JSON sono in chiaro. Nessuna sincronizzazione o integrazione con dispositivi.

I promemoria nell’app richiedono la pagina aperta; per gli avvisi ad app chiusa esportare gli allarmi nel proprio calendario e verificarne le impostazioni.

Le previsioni sono stime: CICL0 non è un metodo contraccettivo e non effettua diagnosi.

Powered by [8s2design](https://8s2design.wixsite.com/home).

Installazione come PWA con manifest, icone dedicate e cache offline del contenuto dell’app. Il pulsante si nasconde dopo appinstalled o in modalità standalone; alcuni browser richiedono installazione manuale.
